Implementação
Pipeline do projeto
1
Leitura do CSV
Carrega as 27 capitais com capital, UF, estado, região, latitude e longitude.
pd.read_csv("capitais_brasil_ibge.csv")
2
Consulta à API do IBGE
Requisição ao endpoint de estados — retorna código IBGE e região oficial de cada UF.
requests.get("https://servicodados.ibge.gov.br/api/v1/localidades/estados")
3
JSON → DataFrame + Merge
Converte a resposta JSON em DataFrame e une com o CSV pela coluna UF.
df.merge(df_api, on="uf", how="left")
4
Mapa com filtro por região
Cria um FeatureGroup por região e adiciona marcadores com popup para cada capital.
folium.FeatureGroup(name=regiao) · LayerControl()
5
Exportação do HTML
Salva o mapa como arquivo HTML interativo, pronto para uso no browser.
mapa_regioes.save("mapa_capitais_brasil_regioes.html")
Integração
Conexões com os grupos
GRUPO 1 Banco geográfico
O CSV com lat/long é nosso banco de dados geográfico — cada linha é um ponto no espaço com coordenadas reais.
GRUPO 2 Fontes públicas
Dados vêm diretamente do IBGE. A coluna link_fonte no CSV comprova a origem oficial.
GRUPO 3 APIs (opcional)
Usamos requests para consumir a API do IBGE e enriquecer os dados com código oficial por estado.
GRUPO 4 Dados privados
A estrutura do nosso DataFrame é idêntica à que uma empresa usaria. Só muda a origem: pública vs privada.
GRUPO 5 Data Mart
O filtro por região é um Data Mart — um recorte temático dos dados com propósito específico de visualização.
GRUPO 6 Docker
O projeto tem Dockerfile funcional — qualquer máquina roda o mapa sem instalar nada manualmente.
GRUPO 7 Orquestrador
Nosso pipeline (CSV → API → merge → mapa → HTML) viraria uma DAG no Airflow numa aplicação real — cada etapa seria uma task automatizada rodando no horário definido.
Containerização
Docker
# imagem base Python
FROM python:3

# diretório de trabalho dentro do container
WORKDIR /app

# copia e instala dependências
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# copia os arquivos do projeto
COPY App/mapa.py .
COPY App/capitais_brasil_ibge.csv .

# executa o script ao rodar o container
CMD ["python", "mapa.py"]
Para rodar:
docker run --rm -v "${PWD}\App:/app" pc-python
O container instala pandas e folium automaticamente e gera o mapa_capitais_brasil_regioes.html sem nenhuma configuração manual.
